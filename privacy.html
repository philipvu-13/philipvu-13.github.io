Privacy Policy

Philip Vu Health Tracker  ·  Last updated September 18, 2026

This application is a personal tool used by one person, its developer and sole user, Philip Vu. It has no other users and collects no data from anyone else.

What data is accessed

With the account owner's explicit consent, the application reads the following from the Google Health API using read only scopes.

  • googlehealth.activity_and_fitness.readonly for calories burned, active zone minutes and steps
  • googlehealth.health_metrics_and_measurements.readonly for weight, body fat, resting heart rate, heart rate variability and related measurements
  • googlehealth.sleep.readonly for sleep duration and sleep stages
  • googlehealth.profile.readonly for basic profile information used to identify the account

How the data is used

The data is used for one purpose only, which is to let the account owner review his own fitness and nutrition figures in a personal notes system on his own computer. It is not analyzed on behalf of anyone else and it drives no product or feature used by other people.

How the data is stored

Health data is written to files on the account owner's personal computer. Authentication credentials are stored in a local file on that same computer and are never committed to any public repository. No server, database or hosted service belonging to this application holds the data, because this application has no backend.

Sharing and disclosure

No data is sold, rented, shared, transferred or disclosed to any third party. No advertising, analytics, tracking or profiling services receive any of it. The application makes no outbound transmission of health data of any kind.

Use of Google user data

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is retained on the owner's computer for as long as he finds it useful and can be deleted by him at any time by removing the local files. Access can be revoked at any time at myaccount.google.com/permissions, which immediately stops all further data access.

Children

This application is not directed at children and has no users other than its adult owner.

Changes

Any change to this policy will be posted on this page with a revised date above.
